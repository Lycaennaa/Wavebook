# Wavebook

Wavebook is a native AppKit music player for local audio libraries on macOS 15 or later. Library playback and management stay on your Mac; optional lyric search sends selected metadata to LRCLIB.

## Highlights

- Create manual and smart playlists, manage favorites, and build a playback queue.
- View synchronized `.lrc` lyrics and optionally search LRCLIB.
- Seek on waveforms, apply ReplayGain, and tune playback with a 31-band EQ.

See [FEATURES.md](FEATURES.md) for the full capability list.

## Quick start

Download a release and follow [INSTALLATION.md](INSTALLATION.md) to verify and install it. On first launch, choose one or more local music folders.
