# Code of Conduct

## Expected behavior

Participants are expected to:

- Be respectful and specific when discussing code, design, and user reports.
- Assume good intent while addressing concrete impact.
- Welcome different experience levels and technical perspectives.
- Protect private user data, credentials, and library metadata.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, deliberate disclosure of private information, and disruptive or abusive behavior are not accepted. Publicly exposing an unpatched security issue is also inappropriate; use [SECURITY.md](SECURITY.md).

## Enforcement

Report conduct concerns privately to the maintainers through GitHub. Include the relevant context and links, but do not post private evidence or personal information in a public issue. Maintainers may remove content, restrict participation, or close discussions when needed to protect participants and the project.

This project does not currently publish an enforcement contact address or response-time SLA.
